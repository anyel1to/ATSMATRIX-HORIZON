## ✨ Key Modules & Telemetry

- **Order Flow Aurora**: High-frequency harmonic sine wave canvas capturing real-time liquidity absorption and wave density.
- **Phase Vortex Radar**: Rotating circular vector gauge scanning cross-exchange momentum and directional convection at 60–120 FPS.
- **Book Membrane 3D**: Undulating cyber wireframe topology mesh simulating market depth and order-book friction.
- **Signal Lattice**: 32-channel quantum matrix with dynamic color triggers and audio-synthesized feedback ticks.
- **On-Chain Whale & Arbitrage Radar**: Streaming live feed tracking institutional transfers, triangular arbitrage fills, and social momentum.
- **Gemini Market Intel Agent**: Interactive drawer where visitors can query Google Gemini for real-time technical analysis and on-chain liquidity breakdowns.
- **Zero-Dependency Single File**: 100% self-contained HTML5, CSS3, Web Audio API, and Canvas engine.
